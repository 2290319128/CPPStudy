# 题目 1｜机器人关节角度统计

## 2. 面试题描述

机器人运行时，某个关节在不同时刻记录了 `N` 个角度（此题统一用**弧度 rad** 表示）。请编写一个 C++ 程序：

1. 读入角度数据的数量 `N`。
2. 读入 `N` 个角度。
3. 计算并输出这些数值的**算术平均值**。
4. 计算并输出这些数值的**最大值**。

**示例输入**（第一行是样本数，第二行是角度）：

```text
4
0.1 0.2 0.3 0.4
```

**示例输出**：

```text
平均关节角度: 0.25
最大关节角度: 0.4
```

> 注：关节角一般以 rad 为单位，本文使用这一约定。如果输入的是度（°），算术运算本身仍可运行，但不能把结果直接当作 rad 使用。

## 3. 数学原理

令采样结果为 $q_1,q_2,\ldots,q_N$，其中 $q_i$ 是第 $i$ 个采样角度。

### 3.1 算术平均值

$$
\bar q=\frac{1}{N}\sum_{i=1}^{N} q_i
=\frac{q_1+q_2+\cdots+q_N}{N}
$$

举例：

$$
\bar q=\frac{0.1+0.2+0.3+0.4}{4}=0.25\ \mathrm{rad}
$$

### 3.2 最大值

$$
q_{\max}=\max(q_1,q_2,\ldots,q_N)
$$

实现的基本思路是“边读边比较”：遇到比当前最大值大的数，就更新最大值。

**重要边界情况：** 如果全部角度都是负数，例如 `-0.8 -0.6 -1.1`，正确最大值应该是 `-0.6`，而不是 `0`。因此不能仅用初始值 `0` 表示已经找到的最大角度；应该在读取**第一个有效数据**时把最大值初始化为该数据。

### 3.3 实际机器人中的含义与限制

- 此题统计的是一组关节角的**普通算术平均值**，适用于关节角数值已经连续展开（unwrapped）或者不会跨越角度表示分界的情况。
- 对于在 $[-\pi,\pi)$ 中环绕的角度，例如 `179°` 和 `-179°`，直接取算术平均值会出现严重误导。圆周角数据需要另外学习**圆形均值/角度展开**。
- 这里是数据统计，**不是**计算一个关节的瞬时角速度，更不是闭环控制器。

## 4. 解题思路（先看思路，再看代码）

1. 定义整型变量 `n`，从键盘输入采样个数。
2. 如果输入不是整数或者 `n <= 0`，拒绝计算，避免除以零或无效数据。
3. 创建可保存 `n` 个小数的 `std::vector<double>`。
4. 初始化总和 `sum = 0.0`。
5. 使用 `for` 循环，从 `i = 0` 读到 `i = n - 1`：
   - 读取 `angles[i]`；
   - 把它加到 `sum`；
   - 如果它是第一项，或者它大于已知最大值，就更新 `max_angle`。
6. 循环结束后计算 `average = sum / n`。
7. 输出结果并结束程序。

## 5. 完整 C++17 代码（逐行中文注释，可直接编译）

**建议文件名：`day01_angle_stats.cpp`**

```cpp
#include <iostream>  // 标准输入输出库：提供 std::cin、std::cout、std::cerr
#include <vector>    // 标准动态数组库：提供 std::vector

int main() {  // main 是整个 C++ 程序的入口函数

    // ===== 第 1 步：读取采样个数 =====
    int n = 0;                       // int 表示整数；n 表示角度样本的数量
    if (!(std::cin >> n) || n <= 0) { // 如果读入失败，或者 n 小于等于 0
        std::cerr << "错误：N 必须是正整数。\n"; // std::cerr 输出错误信息
        return 1;                    // 返回非 0，表示程序出错退出
    }

    // ===== 第 2 步：创建存储关节角度的数组 =====
    // std::vector<double>：存储 double 类型元素的动态数组
    // angles(n)：数组中有 n 个元素；下标从 0 到 n-1
    std::vector<double> angles(n);

    // ===== 第 3 步：定义统计变量 =====
    double sum = 0.0;               // 存放目前已经读取的角度之和
    double max_angle = 0.0;         // 暂存最大值；第一个数据读入时会覆盖它

    // ===== 第 4 步：用 for 循环读取所有角度 =====
    // int i = 0：i 从 0 开始
    // i < n：当 i 小于 n 时继续循环
    // ++i：每完成一次循环，i 增加 1
    for (int i = 0; i < n; ++i) {

        // 从键盘读入一个角度，并放到第 i 个数组元素中
        // 如果用户提供的数据不足，或者输入无法解析为 double，则退出
        if (!(std::cin >> angles[i])) {
            std::cerr << "错误：第 " << (i + 1)
                      << " 个角度读取失败。\n";
            return 1;
        }

        // 累加角度：sum += angles[i] 等价于 sum = sum + angles[i]
        sum += angles[i];

        // 第一项必须用实际数据初始化 max_angle
        // || 表示逻辑“或”：两个条件满足任意一个即为真
        // > 表示“大于”；== 表示“是否相等”（不是赋值）
        if (i == 0 || angles[i] > max_angle) {
            max_angle = angles[i];   // = 是赋值运算符
        }
    }

    // ===== 第 5 步：计算算术平均值 =====
    // sum 是 double；n 是 int；除法结果按浮点数计算
    // 因为已检查 n > 0，所以不会发生除以 0 的问题
    double average = sum / n;

    // ===== 第 6 步：输出统计结果 =====
    // << 用于拼接输出；\n 表示换行
    std::cout << "平均关节角度: " << average << "\n";
    std::cout << "最大关节角度: " << max_angle << "\n";

    // ===== 第 7 步：正常退出 =====
    return 0;
}
```

| `double x = 0.0;` | 创建一个双精度浮点数变量。 | 存储精度更高的关节角和统计结果。 |

| `std::vector<double> angles(n);` | 创建长度为 `n` 的浮点数组。 | 保存关节角度。 |
| `angles[i]` | 取数组中下标为 `i` 的元素。 | 访问本次读入的角度。 |
| `for (初始化; 条件; 更新)` | 循环执行一个代码块。 | 逐个处理角度。 |
| `++i` | 将 `i` 加 1。 | 让循环移动到下一项。 |

| `if (条件) { ... }` | 条件成立才执行。 | 比较最大角度。 |

**`=` 与 `==` 不能混淆：**

```cpp
int a = 3;       // =：把 3 赋值给 a
if (a == 3) {   // ==：判断 a 是否等于 3
    // 条件成立时执行
}
```

**为什么不用 `int` 存关节角？**

因为关节角有小数，例如 `0.125 rad`。如果用 `int`，不能正确表示小数部分。机器人位置、速度、力矩和矩阵计算中，一般大量使用 `double`。

**为什么循环下标从 0 到 n-1，而不是从 1 到 n？**

C++ 的数组下标默认从 **0** 开始：长度为 4 的数组合法下标是 `0、1、2、3`。访问 `angles[4]` 会越界，`operator[]` 不负责进行边界检查，越界会造成未定义行为。

## 7. 复杂度、常见错误与面试追问

### 7.1 时间复杂度与空间复杂度

- **时间复杂度 $O(N)$**：所有角度只扫描一次，一次扫描做有限次加法、比较操作。
- **空间复杂度 $O(N)$**：当前程序把 `N` 个角度都存进 `std::vector`。
- **优化思考**：如果只要求平均值和最大值，其实不必保存所有数据，读取每个角度后立刻统计，就可以把**额外空间复杂度**降到 $O(1)$。后续会学习“流式处理”。

### 7.2 初学者常犯的错误

1. **忘写分号**：`double sum = 0.0` 后面需要 `;`。
2. **把 `=` 当成 `==`**：判断条件中要用比较运算符。
3. **循环写成 `i <= n`**：导致执行 `n+1` 次，其中最后一次数组越界。
4. **最大值初始设置成 0 后从不对第一项特殊处理**：全是负数时错误。
5. **没有检查 `n > 0`**：`n = 0` 会让平均值的除法失效。
6. **用 `int sum` 存浮点角度**：会损失小数。
7. **以为 `vector` 表示数学上的列向量**：本讲中它是 C++ 容器，并不是 Eigen 的线性代数向量类型。

### 7.3 面试官可能问什么？

**Q1：为什么使用 `std::vector` 而不是 `double angles[100]`？**  
A：`std::vector` 的大小可以在运行时根据 `N` 设置，不需要猜一个固定容量；还可以通过标准库接口访问、遍历和管理。固定长度数组适合某些大小已知的场景，但本题输入长度不固定。

**Q2：为什么不直接写 `max_angle = 0.0` 然后始终比较？**  
A：有可能所有角度都是负数。最大值必须由真实输入数据初始化才具有数学上的正确性。

**Q3：如果有 1,000,000 个数据，能否只用常数额外内存？**  
A：可以。用临时变量接收一次输入后立刻更新 `sum` 与 `max_angle`，不需要保留完整序列。

**Q4：普通角度平均值什么时候会有问题？**  
A：当关节角或姿态角按周期包裹存储、跨越 `-π/π` 边界时，直接做算术平均值可能失去几何意义，需要使用角度展开或圆周统计方法。

# 题目 2｜手写一维机器人关节 P 控制器及力矩限幅

## 9. 面试题描述

有一个机器人单关节位置控制任务，已知：

- 目标角度 $q_{\mathrm{ref}}$，单位 rad；
- 当前角度 $q$，单位 rad；
- 比例增益 $K_p$，如果把输出定义为力矩，其单位是 $\mathrm{N\cdot m/rad}$；
- 最大允许输出力矩 $\tau_{\max}>0$，单位 $\mathrm{N\cdot m}$。

要求编写代码计算位置误差、未限幅力矩和限幅后的**最终输出力矩**。

**输入格式**（一行输入四个数字）：

```text
1.2 0.8 10 3
```

依次对应 `target current kp max_torque`。

**期望输出**：

```text
位置误差: 0.4
未限幅力矩: 4
最终控制力矩: 3
```

## 10. 控制原理（建议理解清楚后再敲代码）

### 10.1 第一步：计算位置误差

$$
e=q_{\mathrm{ref}}-q.
$$

当 `target = 1.2 rad`、`current = 0.8 rad` 时：

$$
e=1.2-0.8=0.4\ \mathrm{rad}.
$$

因此当前角度比目标角度小，误差为正。具体正误差对应正向还是反向力矩，取决于关节坐标和执行器符号约定；本题约定正增益和正误差得到正输出。

### 10.2 第二步：P（比例）控制律

$$
\tau_{\mathrm{raw}}=K_p e
=K_p(q_{\mathrm{ref}}-q).
$$

在此例中 $K_p=10\ \mathrm{N\cdot m/rad}$，所以：

$$
\tau_{\mathrm{raw}}=10\times0.4=4\ \mathrm{N\cdot m}.
$$

**物理含义：** 对于相同 $K_p$，误差越大，P 控制器计算出的力矩幅值就越大。这并不意味着“增益越大越好”——在真实机器人上，过大增益可能激励振动或影响稳定性。

### 10.3 第三步：加入力矩饱和约束

实际电机、减速器与驱动系统都有限定的允许输出。我们将控制力矩限制在：

$$
-\tau_{\max}\le\tau_{\mathrm{cmd}}\le\tau_{\max}.
$$

数学形式为：

$$
\boxed{\tau_{\mathrm{cmd}}=
\min\!\left(\tau_{\max},\max(-\tau_{\max},\tau_{\mathrm{raw}})\right)}
$$

等价的分段函数：

$$
\tau_{\mathrm{cmd}}=
\begin{cases}
\tau_{\max}, & \tau_{\mathrm{raw}}>\tau_{\max},\\[4pt]
-\tau_{\max}, & \tau_{\mathrm{raw}}<-\tau_{\max},\\[4pt]
\tau_{\mathrm{raw}}, & -\tau_{\max}\le\tau_{\mathrm{raw}}\le\tau_{\max}.
\end{cases}
$$

当前例子中 $\tau_{\mathrm{raw}}=4$，而 $\tau_{\max}=3$，所以：

$$
\boxed{\tau_{\mathrm{cmd}}=3\ \mathrm{N\cdot m}}
$$

### 10.4 为什么负力矩也必须限幅？

如果目标角小于当前角，例如：

$$
q_{\mathrm{ref}}=0.5,\quad q=1.0,\quad K_p=10,
$$

则：

$$
e=-0.5,\qquad \tau_{\mathrm{raw}}=-5\ \mathrm{N\cdot m}.
$$

在 $\tau_{\max}=3$ 时，输出必须是 **$-3$ 而不是 $-5$**。因此上限和下限都要检查。

### 10.5 这是一个简化模型，而不是真实机器人的完整控制系统

- 代码只计算**单次控制指令**，没有定时循环、关节动力学模型或真实驱动器接口。
- 真实关节受到惯量、重力、摩擦、阻尼、传动等因素影响，仅有 P 控制不一定能实现无稳态误差的精准位置控制。
- 真实机器人的控制律常扩展为 PD、重力补偿或计算力矩控制：

$$
\tau=K_p(q_{\mathrm{ref}}-q)+K_d(\dot q_{\mathrm{ref}}-\dot q)+g(q),
$$

其中 $g(q)$ 表示重力项；这只是典型结构示例，具体定义取决于控制框架。
- **限幅不是完整安全系统**：还需要电流/温度/速度/位置等硬件与控制层保护，且应关注执行器实际能力与通信故障。

## 11. 解题步骤

1. 用四个 `double` 变量接收目标位置、当前位置、比例增益、力矩上限。
2. 检查输入格式正确；本题约定 `kp >= 0` 且 `max_torque > 0`。
3. 使用 `error = target - current` 计算误差。
4. 使用 `raw_torque = kp * error` 计算 P 控制器力矩。
5. 将 `raw_torque` 复制到 `torque`，再用 `if` / `else if` 限幅。
6. 输出误差、原始力矩与最终力矩。

## 12. 完整 C++17 代码（逐行中文注释，可直接编译）

**建议文件名：`day01_p_controller.cpp`**

```cpp
#include <iostream>  // 使用 std::cin、std::cout、std::cerr

int main() {  // 程序从这里开始执行

    // ===== 第 1 步：定义输入变量 =====
    // target：目标关节角（rad）
    // current：当前关节角（rad）
    // kp：P 控制器的比例增益（N·m/rad）
    // max_torque：允许的正、负力矩绝对值上限（N·m）
    double target = 0.0;
    double current = 0.0;
    double kp = 0.0;
    double max_torque = 0.0;

    // ===== 第 2 步：读入控制参数 =====
    // 可以在同一行输入四个数字，例如：1.2 0.8 10 3
    // >> 会按先后顺序把输入赋值给四个变量
    if (!(std::cin >> target >> current >> kp >> max_torque)) {
        std::cerr << "错误：请输入四个数字。\n";
        return 1;
    }

    // 本题只允许非负比例增益，以及严格正的力矩上限
    // || 表示“或”，条件任意一侧为真就进入 if
    if (kp < 0.0 || max_torque <= 0.0) {
        std::cerr << "错误：Kp 必须 >= 0，最大力矩必须 > 0。\n";
        return 1;
    }

    // ===== 第 3 步：计算关节角度误差 =====
    // 数学式：e = q_ref - q
    double error = target - current;

    // ===== 第 4 步：执行 P 比例控制计算 =====
    // 数学式：tau_raw = Kp * e
    // * 表示乘法运算
    double raw_torque = kp * error;

    // ===== 第 5 步：对力矩进行饱和限制 =====
    // 拷贝一份未限幅力矩；保留 raw_torque 便于调试
    double torque = raw_torque;

    // 情况 A：如果计算力矩超过正上限，则截断到 +max_torque
    if (torque > max_torque) {
        torque = max_torque;
    }
    // 情况 B：否则，如果低于负下限，则截断到 -max_torque
    else if (torque < -max_torque) {
        torque = -max_torque;
    }
    // 情况 C：如果处于 [-max_torque, max_torque]，保持原值
    // 此时什么都不用做，因此可以省略最后的 else

    // ===== 第 6 步：输出计算结果 =====
    std::cout << "位置误差: " << error << "\n";
    std::cout << "未限幅力矩: " << raw_torque << "\n";
    std::cout << "最终控制力矩: " << torque << "\n";

    // ===== 第 7 步：结束程序 =====
    return 0;
}
```

### 12.1 最核心的几行代码必须能默写

```cpp
double error = target - current;   // 位置误差 = 目标 - 当前
double raw_torque = kp * error;   // 误差乘比例增益

double torque = raw_torque;       // 保留原始值，准备限幅
if (torque > max_torque) {         // 如果超过正上限
    torque = max_torque;          // 把输出设为正上限
} else if (torque < -max_torque) { // 如果低于负下限
    torque = -max_torque;         // 把输出设为负下限
}
```

这里 `else if` 的作用是：**只有前一个 `if` 不成立，才检查它自己的条件**。

### 12.2 本题语法知识总结

| 代码 | 含义 | 常见错误 |
|---|---|---|
| `double target = 0.0;` | 声明并初始化小数变量。 | 写成 `int` 导致输入小数丢失。 |
| `std::cin >> a >> b;` | 连续读取两个输入值。 | 搞错输入顺序。 |
| `double error = target - current;` | 定义误差并做减法。 | 把 `target - current` 写反。 |
| `kp * error` | 计算比例控制量。 | 将 `*` 错写为 `×`。 |
| `if (torque > max_torque)` | 检查超过正向最大允许输出。 | 忘记负向限制。 |
| `else if (torque < -max_torque)` | 检查超过负向最大允许输出。 | 少写负号。 |
| `torque = max_torque;` | 用限幅值覆盖结果。 | 误将 `=` 写成 `==`。 |
| `std::cout << torque` | 输出控制结果。 | 输入使用 `>>`，输出使用 `<<`，不要颠倒。 |

### 12.3 限幅也可以怎么写？（了解即可）

在学会 `if / else if` 之后，C++17 还提供 `std::clamp`：

```cpp
#include <algorithm>  // 声明 std::clamp

// C++17：把 x 限制到 [low, high]
double torque = std::clamp(raw_torque, -max_torque, max_torque);
```

它与上面的三段判断在**有限、有效的普通数值输入**下实现相同的限幅目的。今天先学手写 `if / else if`，因为面试会要求你清楚算法如何工作；之后再练 STL 接口。

## 14. 复杂度、常见错误与面试追问

### 14.1 时间复杂度与空间复杂度

本题只进行固定次数的读入、加减乘和比较：

$$
\text{时间复杂度}=O(1),\qquad \text{额外空间复杂度}=O(1).
$$

### 14.2 常见错误

1. **误差方向写反**：`current - target` 会改变控制作用方向，需要结合约定确认。
2. **漏掉负向限幅**：超过负的力矩边界时会输出过大的负力矩。
3. **把 `-max_torque` 写成 `max_torque`**：会使负向饱和输出错误变正。
4. **误把弧度和角度混用**：控制增益的单位也必须同步匹配。
5. **错误理解 P 增益**：增益大不等于实际响应一定更快且稳定。
6. **把这段代码误认为完整控制循环**：它只算一次数，不会驱动真实机器人。
7. **允许力矩上限为负**：本题规定 `max_torque > 0`，负值没有符合定义的物理意义。

### 14.3 面试官追问（附参考答案）

**Q1：什么是 P 控制？为什么叫“比例”？**  
A：控制量与误差成正比，$\tau=K_pe$，比例系数是 $K_p$。

**Q2：如果目标位置比当前值小，输出一定为负吗？**  
A：在本题定义的误差方向与 $K_p\ge0$ 假设下，是的。但如果控制器还叠加前馈力矩或采用不同的正方向约定，总力矩不一定为负。

**Q3：为什么要做限幅？**  
A：让计算得到的控制指令遵循执行器允许范围，防止仅由这一指令造成超过设定上限的请求；但这不代表已完成全部机器人安全保护。

**Q4：为什么机器人常用 PD，而不是只有 P？**  
A：速度误差反馈可增加阻尼效果、改善瞬态表现。在存在重力或恒定扰动时，单纯 P 通常不能保证零稳态误差，所以可能需要额外补偿或积分等结构。

**Q5：为什么说这个例子与 MPC 有关系？**  
A：MPC 中也常有位置误差惩罚和输入幅值约束。本题的 $e=q_{\mathrm{ref}}-q$ 是最简单的跟踪误差，$|\tau|\le\tau_{\max}$ 是最简单的输入边界。不同点在于 MPC 通常利用预测模型，联合优化未来一段时域的控制序列，而不只是对当前误差直接乘增益。

**Q6：如果改成多个关节怎么办？**  
A：误差可扩展为向量 $\boldsymbol e=\boldsymbol q_{\mathrm{ref}}-\boldsymbol q$，比例控制器可写作 $\boldsymbol\tau=K_p\boldsymbol e$（$K_p$ 可取对角增益矩阵），每一维按对应执行器限制进行约束或投影；真实耦合关节还需考虑动力学。

<details>
<summary>题目 1：如何做到 O(1) 额外空间？</summary>

如果只需统计结果，不用保存完整序列，核心循环可以这样写：

```cpp
double sum = 0.0;
double max_angle = 0.0;

for (int i = 0; i < n; ++i) {
    double angle = 0.0;       // 一个变量复用 n 次
    if (!(std::cin >> angle)) {
        std::cerr << "输入失败\n";
        return 1;
    }
    sum += angle;
    if (i == 0 || angle > max_angle) {
        max_angle = angle;
    }
}
```

这里不再分配长度为 `n` 的数组，因此额外空间是 $O(1)$。前提仍然是已经正确读取并验证了正整数 `n`。
